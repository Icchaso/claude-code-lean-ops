# /go — 検証して仕上げる

追加の完了条件: $ARGUMENTS

1. 検証: CLAUDE.md の検証コマンド（なければ package.json 等から推定）を実行し、失敗は根本原因を直して再実行する。テストの削除・skip・型の握りつぶしで通さない
2. 簡素化: 今回の差分だけを見直し、不要な抽象化・重複・デバッグ用コード・未使用コードを削る。何か変えたら 1 に戻る
3. 独立レビュー: サブエージェントに差分と完了条件（SPEC.md があればそれ）だけを渡し、正しさと要件漏れだけを指摘させる。妥当な指摘だけ直す
4. 報告: 変更点（3行以内）/ 実行した検証コマンドと結果 / 未検証・リスク。画面での確認が必要な変更なら、ユーザーに `/verify` を勧める
5. コミット: 意味のある単位で。push と PR 作成は指示があった場合のみ
